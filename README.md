# LeanFrontend · 前端面试题库

## 入口

- [基础题库（251 道 / 10 模块）](./index.html)
- [场景追问题库（12 条场景链 / 60 道递进题）](./scenarios.html)

场景题围绕「澄清与定位 → 原理 → 方案 → 边界 → 验证」展开，支持按领域、练习顺序和关键词筛选；每一层先独立作答，再展开参考思路。场景卡片关联已有基础题模块，并附最小实验和来源标注。练习标记仅保存在当前浏览器本地。

**来源说明：** 用户亲历的问题与公开面经中的主题会分别注明；为训练设计的延伸追问不代表企业面试原话，也不等于具有统计意义的面试频率。P1/P2/P3 是本题库的复习顺序，并非外部频率排名。

本仓库保留各基础模块原有独立 HTML；打开 `index.html` 可复习基础知识，打开 `scenarios.html` 可练习跨模块的实际问题与连续追问。
